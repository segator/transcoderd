## Why

The activity filters combine unexpectedly, prefetched jobs appear among active encodes, and the server queue list occupies space needed for local work. Encodes do not show the original file size.

## What Changes

Show the source size for encodes, provide mutually exclusive activity filters with a Prefetch category, retain the server queue count, and allocate the full activity width to local jobs.
