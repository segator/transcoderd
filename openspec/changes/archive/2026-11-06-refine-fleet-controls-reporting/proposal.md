# Proposal

## Why

Promotional copy obscures navigation, mobile charts waste space, and global savings appear to follow a period selector. Operators also need task progress and individual encode controls in each worker card.

## What Changes

- Replace promotional headings and repeated explanations with concise navigation and contextual labels.
- Add custom date ranges, measured range savings, and explicit selected-period versus live/all-time groups.
- Show worker tasks with progress and acknowledged individual RAM pause/resume.
- Use compact responsive chart grids without sacrificing control readability.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `operations-dashboard`: date-scoped measurements, individual remote encode controls and compact presentation.

## Impact

Frontend assets, dashboard API/repositories, worker control protocol and additive migration. Existing preset-hours clients and version-1 worker-wide controls remain compatible.
