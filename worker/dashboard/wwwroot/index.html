Pause behavior

Choose how encoding is suspended immediately.

RAM pause suspends active CPU and GPU encoders and resumes the same encoding without losing progress or changing compression. RAM and GPU VRAM remain allocated. This state is lost if the worker exits or the PC shuts down or restarts.
Used by Pause encodes and individual row controls. Stop after current is separate and lets running encodes finish. RAM and VRAM remain allocated during RAM pause.
Both profiles draw from the same server queue. Either profile may receive any job, depending on which requests it first.
